HOW TO USE THIS FILE (delete this section before publishing, or leave it —
publish.js ignores anything after the line above, it's just for reference):

1. Copy this file and rename it to something like:  cheapest-online-mca-2026.txt
2. Fill in the fields above the "---" line. Only "title" is required —
   everything else (slug, date, author, read time, meta title) fills in
   automatically if left out.
3. Write your content below the "---" line using the simple rules shown
   above (blank line = new paragraph, ## = heading, - = bullet list).
4. Save the file inside the blog-posts/ folder.
5. Run this ONE command from the project root:

       node publish.js

6. Commit and push (or upload) the files it changed: js/blog-data.js,
   the blog/ folder, and sitemap.xml.

That's it — no more editing JavaScript, no more running two scripts in the
right order, no more risk of a typo breaking the whole site.
